# Данные проекта

## Источник

Набор данных **German Credit Risk** из репозитория UCI/OpenML.

- **Ссылка:** https://www.openml.org/d/31
- **Лицензия:** открытый датасет
- **Объём:** 1000 записей, 20 признаков + целевая переменная

## Как получить данные

Запустите скрипт загрузки:

```bash
python data/download_data.py
```

Скрипт загрузит датасет из OpenML и сохранит его как `german_credit.csv`.

## Описание файла

- `german_credit.csv` — основной датасет (создаётся скриптом download_data.py)

## Примечания

- Датасет **не содержит** персональных данных третьих лиц
- Данные являются **открытыми** и **анонимизированными**
- Размер файла ~50 KB
