# Артефакты проекта

В этой папке хранятся обученные модели и результаты экспериментов.

## Файлы

- `model.pkl` — обученная финальная модель (Gradient Boosting)
- `preprocessor.pkl` — обученный препроцессор (LabelEncoder + StandardScaler)
- `results.json` — результаты сравнения всех моделей

## Как создать артефакты

Запустите обучение:

```bash
python -m src.models.train
```

## Примечание

Артефакты не хранятся в Git (добавлены в .gitignore), так как их можно воспроизвести запуском обучения.
Однако для удобства проверки модель и препроцессор включены в репозиторий.
